# 🎡 转盘习惯游戏 (Wheel Habit Game)

生活是各习惯发生期望的总和，而非单次幸运的偶成。**转盘习惯游戏**是一款基于「不确定性概率发生期望」与「全员期望加权结算」的创新全栈型习惯/限令管理应用。

通过将习惯的日常奖励/惩罚数值绑定到具有「占格权重」的概率大转盘中，让单次的转盘转动决定今日的执行目标，同时在每次旋转中将全体参与习惯以 `占格权重 × 习惯分值` 进行全账目期望值清算。这让用户能够在应对随机转动的乐趣中，获得扎实稳定的长期习惯复利，科学调控自己生活中的好习惯占比。

---

## 🎨 视觉与核心设计理念

- **无感多源同步**：同时支持 **Firebase Firestore** 顶级全栈云存储与全离线 **Local Storage** 完美的本地游客模式，在任何运行环境下均能获得流畅完整的体验。
- **高对比科技美学**：采用 Indigo 靛蓝、Slate 灰、Emerald 翠绿与 Rose 玫瑰红作为色彩核心，结合精致的旋转缓动动画、高气势的居中结果同步展示弹窗，打造极具仪式感的操作体验。
- **分值驱动自适应派色**
  - 转置取消了自定义手动点选颜色的操作，改由系统根据习惯的**权重分值**自动进行色彩层级渲染。
  - **负向习惯**：负分数 -1 到 -10 会自动映射成从浅红色到深红色（R 处于 25~255 的深度变化区间），分值在 -10 以下的部分保持红度饱和。
  - **正向习惯**：正分数 1 到 10 会自动映射成从浅绿色到深绿色（G 处于 25~255 的深度变化区间），分值在 10 以上的部分保持绿度饱和。
- **全方位防误触与容错**：习惯删除、历史账目清空、全库覆盖导入等关键高危操作，全部配备了优雅、清晰的前端交互式二次确认弹层。

## 🚀 核心功能模块

### 1. 🗄️ 习惯分值仓库（事件库）
- **自定义事件**：用户可在此添加新的习惯项目（如“早睡早起”、“冥想”、“乱吃零食”）、设定性质级别（积极、消极、中性）及单次期望加减积分权重。
- **二次防误触删除确认**：彻底删除仓库中已存习惯时，会有明确的弹窗警示用户该删除也将同步清退转盘配置，拒绝手滑误操作。
- **一键批量文字导入**：支持利用纯文本一键批量粘贴导入习惯。提供额外的 **「清除全部现有事件」** 复选框选项，打勾时支持覆盖式全面重洗仓库，不打勾则为追加合并模式。

### 2. 🎯 习惯转盘（占格调平）
- **权重自适应修正**：可直接将配制好的习惯拖入至当前的转盘上设定“占格数（权重总计必须严格等于 100 格）”。
- **单边比例红线约束**：积极与消极习惯各自的最大占格不能超过 80%，避免转盘配置两极分化。
- **转动效果与算法**：点击“旋转转盘”，基于真实随机数计算阻力缓动阻尼直至确定目标习惯。结果产生后触发全屏模态弹窗进行即时奖励分。

### 3. 📅 实时习惯积分与周结账本
- **初始动能 0 分制**：初载分值设定为 `0`。支持通过“周清归零结算”一键清零进行周期重整，也支持“手动分数修正”方便根据现实情况随时调整当前记账积分。
- **概率结算期望算式**：每次转动后不仅会指明其中签的一项习惯，本轮的总体积分增损计算方式更基于综合概率均值核算：
  $$\text{本次积分损益} = \sum (\text{单项权重分值} \times \text{对应分配格占比})$$
  这促使您为了控制积分不会持续滑坡，就必须尽力压缩不良在转盘的占格，并扩充好习惯的主导比例。

### 4. 🎯 今日执行清单
- **精确定向**：转盘摇出的获选习惯，会自动作为「当期落实任务」以未完成状态载入执行待办清单。
- **日常勾销与一键清空**：用户在当日将该习惯执行到位后即可勾选划掉；执行清单亦支持安全二次确认下的完整一键清空。

### 5. 📜 转盘结算明细账本
- **公式全要素归档**：提供折叠式明细账单，完整、可追溯地记录了每一次旋转产生的随机数、积分累进走势以及本次所有项目按各自占格乘比折算的细项算式。
- **位置语义归位**：清账功能专属按钮内嵌在明细历史顶部右侧，并配备交互确认，提供良好紧凑的视觉语境。

### 6. 云端自动序列备份
- **双向无缝同步**：登录账户后，程序会自动启动 Firestore 跨端备份机制。
- **800ms 防抖瞬时保存**：增删清单、旋转转盘、配置发生变动，均会在静止约 `800ms` 后向 `users/{uid}/userData/config` 云端节点推送归档。保障多设备无感恢复。

## 🛠️ 技术栈清单

- **前端框架**：`React 18` + `Vite 4` (带 TypeScript 全程强合规类型推导)
- **视觉美化**：`Tailwind CSS v4` 配合原生 `@import` 设计规范
- **图标生态**：`lucide-react` 
- **离线支撑**：`Local Storage` 自适应挂载技术
- **云端服务**：`Firebase Authentication` (账号密码隔离体系) + `Firestore` (结构极简归档备份)

## ⚙️ 快速启动

1. 在项目根目录下，安装依赖包：
   ```bash
   npm install
   ```
2. 在项目根目录下，使用开发服务器运行本地预览（绑在 Port 3000 上）：
   ```bash
   npm run dev
   ```
3. 构建并输出静态托管资源：
   ```bash
   npm run build
   ```

### 云端配置方式 (Firebase Setup)
若期望使用云端的实时账号存储与同步性能，请在 AI Studio 的 **Settings** 中，正确输入以下 4 个环境变量：
- `VITE_FIREBASE_API_KEY`
- `VITE_FIREBASE_AUTH_DOMAIN`
- `VITE_FIREBASE_PROJECT_ID`
- `VITE_FIREBASE_APP_ID`
